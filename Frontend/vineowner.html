Server-managed settings

Secrets, payment keys, service-role keys, and bootstrap credentials must be set in Render environment variables or Supabase—not in this HTML page.

This initial release exposes the owner/staff/role/permission foundation. Store branding, payment configuration, notification providers, delivery pricing, and service health controls will be connected after their server-side settings APIs are added.
  • Owner identity is checked by the accounts API.
  • Staff credentials are managed by Supabase Auth.
  • Role and permission data is stored in the Vine accounts database.
  • Existing Store and Operations API routes still need migration from fixed roles to dynamic permission checks before arbitrary permissions can govern every existing action.
